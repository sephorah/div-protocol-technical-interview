● I have what I need. Two things the exploration turned up that change the shape
  of this issue:

  - Compose resolves .env and the project name from the compose file's directory
  (verified: --project-directory /tmp made interpolation fail even with .env in
  cwd). Moving the file to infra/ therefore breaks .env lookup and renames the
  project to infra.
  - Both compose files currently share the project name exo2-portail-depot
  (verified via docker compose ls / config). pnpm db:up while the prod stack is
  up would recreate prod's db/minio with dev config and a dev volume. A5 is the
  natural place to fix that.
